# 《共践哲学》 — 开源版（仓库主页）

感谢你关注并使用本仓库。这份仓库旨在把《共践哲学》的文本以开源、可参与的方式发布，方便阅读、校对、翻译与长期保存。

主要说明：
- 许可：本文档及仓库文本采用 Creative Commons Attribution-ShareAlike 4.0 International（简称 CC BY‑SA 4.0）。你可以复制、改编、传播，但必须署名并以相同许可发布衍生作品。
- 署名要求：请署名 "作者：mike1512384"（或在学术引用中写作者姓名，详见 CITATION.cff）。

当前状态：
- 我已在本仓库创建了一个演示网站（Docsify）和示例章节，放在 docs/ 下。打开 GitHub Pages（仓库设置 -> Pages）并将 Source 设为 "main branch / docs folder"（或合并 PR 后再启用），即可访问在线书籍。

如何把你的全部文本上传（简单三种方式，推荐 2）：
1. GitHub 网站（手动一章一章粘贴）：适合不想安装任何软件的人，但一次只能上传少量文件。
2. GitHub Desktop（推荐）：图形界面，适合一次性上传整套 7 卷文件（我会提供逐步截图说明）。
3. git 命令行：适合熟悉命令行的用户。

下一步我可以替你把全部文本上传——如果你愿意，把整理好的压缩包（每卷为一个文件夹，章节为 MD 文件）通过你方便的方式发给我（例如上传到你能分享的网盘并把链接发来），我会代为把文件放入 docs/content/ 并发起 PR。或者你也可以在本分支中先查看演示模板并手动上传。

如果你还不熟悉任何步骤，我可以：
- 将本分支（`init/docsify-setup`）中的演示文件提交为 PR；
- 在 PR 中附上非常详细的逐步图文说明，教你如何用 GitHub Desktop 一次性上传 7 卷所有文件；
- 或者在你给出文本压缩包下载链接后，代为上传全部内容并发起 PR。

署名与联系：我会保留并强调你（作者）的署名权，仓库内的示例与元数据（CITATION.cff、README）会提示读者如何引用并署名。
